# Customer Support Page

## Goal
Build one polished customer-service page inspired by the supplied reference, with the same dark navy, teal, and WhatsApp-green visual language.

## Page content
- Compact header with brand mark and section links that scroll within the same page
- First screen with support headline, short introduction, prominent WhatsApp contact action, trust notes, and a custom phone/chat illustration
- Three-step “How to Get Support” section
- Trust section covering privacy, professional support, and quick response times
- Responsive mobile and desktop layouts with subtle motion and clear focus states

## Visual direction
- Near-black navy background with restrained teal glow and thin borders
- Bright mint/green primary actions, white headings, and muted blue-gray supporting text
- Geometric sans-serif typography, compact labels, luminous icons, and crisp low-radius panels
- No copied screenshot asset; the page will be recreated with native page elements and icons

## Technical notes
- Keep this as the only content page at `/`
- Use the project’s existing React page system and Tailwind CSS design tokens
- Keep navigation in-page only; no extra pages or backend will be added
- Use placeholder brand and WhatsApp details where the brief does not supply them
- Add page-specific title and social metadata
